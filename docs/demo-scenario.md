# ARA 시연 시나리오

> **목적**: 채점자/검토자가 5분 안에 전체 기능을 확인할 수 있도록 안내합니다.
> **데이터**: `samples/sample_ledger_2024.xlsx` — **더미 데이터. 실제 회사 데이터가 아닙니다.**

---

## 시연 환경 설정

1. 백엔드 + 프론트엔드를 기동합니다 (README 빠른 시작 참고)
2. `PwC_LLM_API_KEY` 없이도 **mock 모드**로 전체 흐름 시연 가능합니다
3. 더미 분개장 생성:
   ```bash
   cd samples && python generate_sample.py
   ```

---

## 시나리오 1 — 매입채무 분석 (기본 흐름)

### Step 1: 프로젝트 생성

| 항목 | 입력값 |
|------|--------|
| 회사명 | (주)샘플제조 |
| 회계연도 | 2024 |
| 당기 | 2024-01-01 ~ 2024-12-31 |
| 전기 | 2023-01-01 ~ 2023-12-31 |
| 중요성 금액 | 50,000 천원 |

### Step 2: 계정과목 추가

- 계정과목명: `매입채무`
- 유형: `부채`
- 분석 모드: `잔액 자동 필터 (ZIP 업로드)`
- 입력 방법: `ZIP/Excel 업로드`

### Step 3: 명세서 업로드

1. `samples/sample_ledger_2024.xlsx` 업로드
2. ARA가 자동으로 시트를 감지합니다:
   - 집계 시트: `집계표`
   - 증감 시트: `증감분개`
   - 기초잔액 시트: `기초잔액`
3. 감지된 컬럼 확인 (거래처명, 금액, 전기일 등)
4. **확정** 클릭 → 5개 거래처 구성요소로 자동 구성

### Step 4: AI 분석

1. **AI 사유 생성** 버튼 클릭
2. 버튼 텍스트: `요약 생성 중... → 사유 생성 중...` (단계 표시)
3. 완료 후:
   - 분석적 절차 요약 텍스트 자동 입력
   - 각 구성요소별 증감 사유 생성

### Step 5: Risk Score 확인

- `(주)가나무역`: 5월 이상 매입(310,000)으로 critical 또는 high 위험도
- `(주)라마건설`: 신규 항목(기초 0, 기말 80,000) → +20 가산

### Step 6: 분개 드릴다운

1. `(주)가나무역` 행의 **보기 (11)** 버튼 클릭
2. 분개 모달 오픈 → `5월 특별매입 310,000` 행이 **이상치** 배지와 함께 강조
3. ESC 또는 닫기로 모달 종료

### Step 7: 파레토 차트

1. 계정과목 상세 상단의 **잔액 분포 (파레토 차트) ▼** 클릭
2. 상위 3개 거래처가 전체 잔액의 약 80% 이상 구성하는 것을 확인

### Step 8: Excel Export

1. **Excel Export** 버튼 클릭
2. `(주)샘플제조_2024_매입채무_YYYYMMDD.xlsx` 다운로드
3. 워크페이퍼 형식: 구성요소 테이블 + AI 총평 + 증감 사유

## 시나리오 2 — 수동 정의 모드

1. 새 계정 추가: `매출채권`, 모드 `구성요소 직접 정의`
2. 분석 지시 입력: `"2024년 주요 거래처 5곳의 매출채권 잔액 변동을 분석하라"`
3. **AI 사유 생성** → 지시 기반으로 구성요소 자동 생성 (mock 모드에서는 mock 응답)
4. + 행 추가로 수동 항목 입력 가능

## 핵심 검증 포인트

| 항목 | 확인 방법 |
|------|-----------|
| mock 모드 동작 | `PwC_LLM_API_KEY` 비운 상태에서 AI 분석 → 정상 mock 응답 |
| 이상치 탐지 | 가나무역 5월 분개(310,000)가 이상치로 표시됨 |
| Risk Score | 신규 항목(라마건설) critical/high 수준인지 |
| ESC 닫기 | 모달 열린 상태에서 ESC 키 → 모달 닫힘 |
| 자동 저장 | 메모 수정 후 5초 내 메타바 "방금 저장" 표시 (toast 없음) |
| Excel 다운로드 | xlsx 정상 다운로드, 내용 확인 |

## 더미 데이터 구조

`sample_ledger_2024.xlsx` 시트 구성:

| 시트명 | 내용 |
|--------|------|
| `집계표` | 계정코드·계정명·기초/증가/감소/기말 잔액 |
| `증감분개` | 전기일·거래처명·적요·증감구분·금액 |
| `기초잔액` | 계정코드·계정명·기초잔액 |

**이상치 설계**: `(주)가나무역` 5월 거래 310,000천원 — 1~4월·6~9월 평균(~51,000천원) 대비 약 z=5 수준
